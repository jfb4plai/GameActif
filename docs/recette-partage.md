# Recette de l'activité partagée (lien et QR)

À faire par JF, sur de vrais appareils. Rien n'est annoncé « vérifié » avant que cette grille soit remplie.
Prérequis (chacun avec votre accord, voir le jalon du plan 9) : migrations `20261103`, `20261107` et `20261108` appliquées sur la base partagée ; variable Vercel `VITE_SUIVI_ACTIF=1` ; déploiement de la branche `feat/activite-partagee`.
Adresse à ouvrir : `https://gameactif.jfb4plai.com/` (le lien d'une activité a la forme `https://gameactif.jfb4plai.com/?activite=CODE`).
Matériel : un ordinateur (ou le TBI) pour l'enseignant, un téléphone, une tablette Android, un iPad, et un compte enseignant GameActif.

## A. Publier

1. Sur l'ordinateur, ouvrir l'adresse, se connecter (« Mon espace »), créer une classe de 5 codes dans « Mes classes et résultats ».
2. Remplir le parcours jusqu'à l'étape « Vos jeux » (exemple : P4, mathématiques, vocabulaire de position).
3. Sous les jeux, ouvrir « Proposer à la classe » : choisir la classe, « Même niveau pour tous », puis « Proposer à la classe ».
4. Vérifier : un QR s'affiche, le lien s'affiche en texte, « Copier le lien » met le lien dans le presse-papiers.

## B. Ouvrir sur les appareils (mode « même niveau »)

| Appareil | Scanner le QR affiché sur l'écran | Activité ouverte | « Qui joue ? » montre E01 à E05 | Remarque |
|---|---|---|---|---|
| Téléphone | | | | |
| Tablette Android | | | | |
| iPad | | | | |

À noter : la distance à laquelle le QR est lu sur le TBI (essayer à 2 m et à 4 m), la luminosité, le temps entre le scan et le premier jeu.

## C. Jouer et voir le résultat

1. Sur une tablette, choisir E02, jouer un tour (au moins une erreur volontaire), puis noter le message d'enregistrement.
2. Sur l'ordinateur, « Mes classes et résultats », ouvrir la classe : E02 apparaît dans « Qui a joué », l'erreur apparaît dans « Erreurs par type ».
3. Sur la tablette, « Rejouer un niveau au-dessus » : jouer le tour. Sur l'ordinateur, le tableau des jeux indique « dont 1 au niveau au-dessus » et les erreurs de ce tour ne comptent pas dans « Erreurs par type ».
4. Vérifier que le mot « Soutien » n'apparaît jamais sur la tablette.

## D. Les autres modes

- **Un lien par groupe** : republier en « Un lien par groupe » : trois QR (vert, bleu, orange). Ouvrir le vert : le niveau annoncé est le plus bas ; le bleu : celui du milieu ; l'orange : le plus haut.
- **Niveau par code** : republier en « Niveau par code », puis dans « Niveaux par code » fixer E03 au niveau Défi. Sur la tablette, choisir E03 : le niveau annoncé change ; choisir E04 (non fixé) : niveau de départ.

## E. Cas limites

- **Lien retiré** : « Retirer le lien », puis rouvrir le lien sur une tablette : « Cette activité n'est plus proposée. »
- **Hors connexion** : ouvrir le lien une fois, couper le Wi-Fi, recharger la page : l'activité s'ouvre avec le message « Activité ouverte sans connexion ». Jouer un tour : le résultat n'est pas enregistré et le message le dit.
- **Rechargement** : recharger la page de la tablette en cours d'activité : l'activité se rouvre.
- **Classe supprimée** : supprimer la classe depuis l'ordinateur, rouvrir le lien : « n'est plus proposée ».
