GameActif : mode d’emploi pour les élèves

Quelques gestes pour jouer.

Jouer avec GameActif

  • Choisir son code dans la liste « Qui joue ? ».
  • Appuyer sur « Jouer ».
  • Lire la consigne, puis choisir une réponse.
  • Appuyer sur « Écouter la consigne » quand ce bouton est proposé.
  • Rejouer un niveau au-dessus après un tour, si l’envie est là.
