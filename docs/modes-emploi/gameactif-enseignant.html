GameActif : mode d’emploi pour l’enseignant

Ce mode d’emploi reprend l’aide repliable de chaque écran de GameActif : à quoi il sert, quoi faire, et ce qu’il ne fait pas.

Parcours, étape 1 : Niveau

  • Choisir le niveau de vos élèves, de P1 à P6 : le programme affiché ensuite est celui de ce niveau.
  • « Voir l’exemple des positions (P4) » ouvre une activité prête à jouer, sans rien saisir.
  • Votre saisie est gardée dans ce navigateur : rien n’est envoyé.
  • Pour reprendre une activité exportée : « Ouvrir une activité (fichier) », en bas de page.

Limite : Rien n’est enregistré en ligne à cette étape : un autre navigateur ne retrouve pas votre saisie.

Parcours, étape 2 : Matière

  • Choisir la matière : elle détermine les attendus proposés à l’étape suivante.
  • Revenir en arrière avec « Précédent » ne perd rien de ce qui est saisi.

Limite : Seules les mathématiques sont disponibles pour l’instant.

Parcours, étape 3 : Compétences visées

  • Cocher de 1 à 3 attendus du programme que l’activité travaille.
  • Chaque jeu sera relié à ces attendus, côté écran et côté classe.
  • Les attendus viennent des référentiels de la Fédération Wallonie-Bruxelles.

Limite : Cocher un attendu ne prouve pas que le jeu le travaille : c’est à vous d’en juger.

Parcours, étape 4 : Vos éléments

  • Saisir vos éléments : mots, paires, étapes, comparaisons, questions.
  • Un jeu devient disponible quand ses données sont suffisantes : son statut est affiché.
  • Le contexte de classe est obligatoire : n’y mettre aucun prénom ni nom d’élève.
  • Relire chaque élément : les élèves verront exactement ce que vous saisissez.

Limite : L’outil ne vérifie pas que vos contenus sont justes.

Parcours, étape 5 : Vos jeux

  • Chaque jeu sur écran a son jeu en classe, sans écran, avec une fiche à imprimer.
  • Le profil règle le nombre d’éléments et les aides ; il ne décide rien pour un élève.
  • « Autres jeux, avec votre IA » donne un texte à coller dans votre outil d’IA, à relire avant usage.
  • « Télécharger mon activité » donne un fichier à partager avec un collègue.
  • Le « Mode calme », en haut de page, coupe les animations.

Limite : Les phrases « lien programme » sont à compléter par vous.

Proposer à la classe

  • Choisir la classe qui reçoit l’activité.
  • Choisir comment décider du niveau : même niveau, un lien par groupe, ou niveau par code.
  • Afficher le QR au TBI ou copier le lien.
  • « Mettre à jour le lien » après une modification ; « Retirer le lien » quand l’activité est finie.
  • Vérifier que l’activité ne contient ni prénom ni nom d’élève : le lien est lisible par quiconque l’a.

Limite : Votre contexte de classe n’est jamais envoyé ; le lien disparaît avec la classe, le 30 août.

Mes classes

  • Créer une classe, puis donner son code aux élèves.
  • Chaque élève joue sous un code (E01, E02…) : garder chez soi la liste des prénoms, elle reste sur cet appareil.
  • Consulter le tableau de bord après chaque séance.
  • Inviter une personne en lecture seule si besoin.

Limite : Les résultats d’une classe sont supprimés le 30 août suivant sa création.

Le tableau de bord

  • Lire d’abord « Qui a joué ».
  • Regarder les erreurs par type : elles disent quoi réenseigner.
  • Les états sont un indice, pas une preuve : décider avec ce qui est observé en classe.
  • Noter ses observations avec le code, jamais le prénom ni le nom.

Limite : Quiconque connaît le code de classe peut enregistrer un résultat sous un code élève : ce tableau n’est pas une preuve.

Niveaux par code

  • Le niveau de chaque code est votre décision, jamais automatique.
  • Standard est le niveau par défaut.
  • L’élève ne voit pas le nom de son niveau.
  • L’élève peut rejouer un niveau au-dessus ; le tableau de bord l’indique.

Limite : Un camarade qui connaît le code de classe peut essayer d’autres codes et deviner un niveau.
